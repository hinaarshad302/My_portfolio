## 📁 Repository Structure

```text
My_portfolio/
├── index.html
├── about.html
├── skills.html
├── projects.html
├── education.html
├── contact.html
├── style.css
├── script.js
└── README.md
```

- **HTML files** contain the content for each portfolio page.
- **style.css** contains the shared layout, sidebar, themes, and responsive styling.
- **script.js** handles interactive features such as the theme toggle and sidebar behavior.

## 🚀 Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser, or use a local development server for a better preview.

No build step is required for this static HTML, CSS, and JavaScript website.
